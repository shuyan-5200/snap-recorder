# Snap Recorder 2.0

**把想法，录清楚。**

一款轻巧、有质感的 Mac 录屏工具。录一段产品演示，讲清一个操作，留住突然出现的灵感。选好画面，按下录制，结束后直接命名保存。

[下载 Mac 版](https://github.com/shuyan-5200/snap-recorder/releases/download/v2.0.0/Snap-Recorder-v2.0.0-macOS-universal.zip) · [浏览产品页](https://shuyan-5200.github.io/snap-recorder/)

## 想展示什么，就录什么

| 录制方式 | 用在这里 |
| --- | --- |
| 任意窗口 | 单独展示一个应用，保持完整窗口比例，不带入桌面和其他窗口。 |
| 整个屏幕 | 跨应用演示；从缩略图确认目标，多显示器可自由切换。 |
| 局部录像 | 框出重点；支持横屏、竖屏、方形与自定义比例，可选圆角和聚焦蒙版。 |

## 一次录好，按需导出

视频、电脑声音、人声可自由勾选，选择合并或分轨，也能只保存声音。视频输出 MP4，独立音频输出 M4A。

**高清 / 日常 / 小巧 / 极小 / 自定义**：保留清晰原始尺寸，或导出更轻巧的分享版。自定义可填写每个视频的 MB 上限；独立音频另计。

保存后，改个名称、大小或声音组合，就能再导出一份。已有文件自动避让，不用担心覆盖。

[![导出内容、声音组合与视频大小](images/v2.0/export.png)](images/v2.0/export.png)

## 让每一步讲解都清楚

- **人像随画面同行**：摄像头画中画，四角位置、圆形或圆角、三档大小与镜像。
- **自然一点，也可以**：原图、自然、柔和，按需选择，只处理摄像头画面。
- **跟得上你的操作**：鼠标准星和点击波纹，配合局部聚焦，突出重点。

[![人像样式抽屉](images/v2.0/portrait.png)](images/v2.0/portrait.png)

## 录制简单，内容安心

**选来源 → 3 秒倒计时 → 录制 → 命名保存。** 随时暂停或继续，录得不满意就重来。文件统一保存在「下载」，录制结束后仍可继续导出。

无需账号，全程本地处理，无上传、无统计。摄像头与人声默认关闭，按需授权；自然修饰不识别身份，不保存人脸数据。

## 2.0 的新体验

- 左侧调人像，右侧做导出，同一个窗口就能完成。
- 多屏缩略图与屏幕切换，让录制目标更明确。
- 四档视频大小跟随原片比例，不再限定固定分辨率。
- 窗口标题自动用于命名，倒计时增加声音提示。
- 修复关闭、确认框和输入交互，让录制到保存更顺畅。

## 安装与使用

macOS 14+，支持 Apple Silicon 与 Intel；人声录制需 macOS 15+。当前版本 **2.0.0 / build 26**。

下载并解压后，把应用拖入「应用程序」。首次使用允许屏幕录制；需要摄像头或人声时再分别授权。应用尚未经过 Apple 公证，首次打开被拦截时，可在「系统设置 → 隐私与安全性」中允许。

| 快捷键 | 功能 |
| --- | --- |
| ⌘R | 开始录制；窗口和整屏模式需主面板在前台。 |
| ⌘E | 局部模式切换选区调整与点击穿透。 |
| Esc | 取消倒计时；录制中结束录制。 |

界面图片由 2.0 原生组件呈现，使用演示窗口与录制参数，点击可查看完整图片。

<summary>录制与导出的关键规则</summary>

- 窗口保持原始比例，整屏与局部录制不录入倒计时、控制条、选区框或摄像头预览浮窗。主面板开始录制时收起，主动打开并放入画面时可录入。
- 多屏录制锁定所选显示器；目标断开时要求重选，不会自动改录其他屏幕。
- 高清、日常、小巧、极小按原片宽高的 100%、75%、50%、25% 等比输出，最高 30 帧；默认高清。自定义按实际文件大小检查上限，小体积可能损失细节。
- 全选分轨会得到无声视频、电脑声音、人声各一份。需要「画面 + 电脑声音」并保留独立人声时，可先合并导出前两项，再单独导出人声。
- 原片保留到完成或放弃导出会话；未保存时主动放弃会移入废纸篓。重复导出不覆盖已有文件，分轨不打 ZIP。
- 人像直接合入视频，预览与成片共用处理结果。关闭摄像头、录制结束或空闲关闭主窗口时释放设备。
- 不提供剪辑、自动变焦或云分享。DRM 受保护内容可能呈现黑屏。
