# Snap Recorder MVP 产品规格

当前规格对应 0.5.0（build 13）。本次重构录制后的导出流程和主面板可截图性。安装与验收状态以 `verification.md` 中对应构建的记录为准。

## 目标

用最短路径完成高质量 Mac 录屏，不进入编辑器，不要求用户设置格式或选择保存目录。

主流程：

未录人声：

`首次授权 → 选择来源 → 3 秒倒计时 → 录制 / 暂停 → 结束 → 命名与画质 → 确认保存到下载 → 可继续导出或重录`

录制人声：

`开启人声并授权 → 录制 → 结束 → 命名、画质与声音版本 → 确认保存到下载 → 可继续导出或重录`

## 三种来源

### 浏览器窗口

- 支持 Safari、Chrome、Edge、Arc、Firefox、Brave、Orion、Opera。
- 只抓选中窗口，其他应用和其他浏览器窗口不进入成片。
- 输出跟随开始录制时的浏览器窗口比例，不拉伸、不裁切；浏览器完整铺满成片。
- 优先保留 Retina 原始像素，最高约 3840×2160。
- 不添加桌面壁纸、渐变、圆角、阴影或额外画布。

### 整个屏幕

- 录制当前主显示器。
- 保持显示器原始比例，不拉伸、不裁切。
- 优先保留显示器原始像素，最大输出约 3840×2160。
- 主面板正常可截图，主动打开并放入录制区域时可以录入；倒计时和控制胶囊不会进入视频。

### 局部录像

- 录制当前主显示器上的可调区域；主面板在开始录制时自动收起，主动打开并移入选区时可以录入；选区框、蒙版框、倒计时和控制胶囊不进入成片。
- 提供 16:9、9:16、4:3、3:4、21:9、1:1 与自定义比例。
- 固定比例通过四角等比缩放；自定义比例支持边缘与四角自由缩放；选区内部可拖动位置。
- 大选区提供方角与圆角，默认圆角；圆角状态可选柔和暗角，只在四个角产生轻微渐隐。
- 固定比例可开启聚焦蒙版。蒙版框可拖动和自由缩放，框内保持原色，框外转为单色并压暗 50%。
- 聚焦蒙版提供方角与圆角，默认圆角；屏幕预览使用低对比灰色细框。
- `⌘E` 在可调整选区与点击穿透浮层之间切换；锁定后框线仍可见，下面的界面可正常操作。
- 主窗口聚焦时 `⌘R` 可开始任意模式录制；局部浮层锁定后 `⌘R` 临时全局生效。录制中与暂停时 `Esc` 全局结束录制。
- 优先保留选区原始像素，最大输出约 3840×2160。

## 全局录制选项

- “电脑声音”“人声（麦克风）”与“摄像头”保持独立开关；人声和摄像头默认关闭。
- “录制鼠标”对浏览器、整个屏幕和局部录像三种模式同时生效，默认开启。
- 开启录制鼠标时不录入系统箭头，由成片合成器绘制圆形高亮光点与柔和光晕；左键、右键或中键点击时，从按下位置产生一次约 0.65 秒的扩散波纹。
- 关闭录制鼠标时，成片不包含光标与点击提示。
- 鼠标位置与按键状态通过公开的会话状态轮询，不新增辅助功能或输入监控权限。

## 摄像头画中画

- 开关加入现有全局录制选项，默认关闭；打开时才申请摄像头权限，不连带开启人声或电脑声音。
- 授权后显示本地实时预览，用户可以在开始录制前检查构图；默认使用右下角圆角方形，中档大小，镜像开启。
- 主窗口内的轻设置提供圆角方形 / 圆形、小 / 中 / 大三档、左上 / 右上 / 左下 / 右下四角位置、镜像与可选自然修饰；不进入编辑器。位置采用 2×2 卡片，整卡可点击，不依赖系统弹出面板。
- 摄像头画面等比填满画中画区域并裁去多余边缘，不拉伸人像；位置、大小与边距以最终成片画布为基准，三种录屏模式保持一致。
- 画中画在录制时直接合入最终画面；摄像头预览浮窗保持不可共享，避免整屏或局部采集重复录入。
- 暂停期间不写入画面；继续录制使用当前摄像头画面，并沿用屏幕与声音的统一时间轴。
- 开关关闭、停止录制、未录制时关闭主窗口或退出应用，均释放摄像头；再次录制时可重新启动预览。
- 权限拒绝、无摄像头、设备被占用或无法启动时给出清晰说明，允许关闭摄像头继续录屏。录制中设备意外断开时停止录制，并尽力保存已录部分，不承诺无法完成封装的内容一定可恢复。
- 自然修饰使用“原图 / 自然 / 柔和”三档，默认原图，不提供连续强度滑杆；自然档保留更多纹理，柔和档加强肤质柔化，两档必须有可验证的像素处理差别。不瘦脸、不美妆、不改变五官形状；检测不到可靠正脸时恢复原图。
- 自然修饰使用免费的苹果原生 Core Image 与 Vision；仅开启时在本机内存中检测人脸区域，预览和编码共用处理后的像素。不处理录制的桌面内容，也不增加网络或第三方依赖。
- 区域检测只用于定位修饰范围，不识别身份；不保存人脸模型、特征向量或检测标记，不上传。摄像头画面及开启的修饰效果会保留在用户主动保存的录像中。

## 状态与反馈

- 未授权：只显示授权说明和唯一主按钮。
- 空窗口列表：明确提示先打开浏览器，并提供刷新。
- 结束后提供“高清 / 日常 / 小巧 / 极小 / 自定义”，默认日常；同时显示尺寸、帧率与预计体积。
- 名称默认包含日期和时间，保存前可改。结束时只完成临时封装，确认后才保存到下载。
- 倒计时：3、2、1，每个数字 1 秒；数字消失后等待约 120 毫秒再启动采集。
- 录制中：顶部胶囊显示红点、真实录制时长、暂停和结束。
- 暂停：红点变橙色，显示“已暂停”；继续时不再次倒计时。
- 处理中：显示“正在整理录制…”或“正在生成视频…”，不显示虚假百分比。
- 导出内容“视频 / 电脑声音 / 人声”分别勾选，默认勾选所有已录内容；未录制的声音不可勾选。
- 输出方式仅“合并 / 分轨”每次单选；有人声时默认分轨，否则默认合并。只选声音时隐藏视频大小。
- 保存成功：同一页面显示累计文件、实际大小和“在访达中显示”，保留命名与所有导出设置，支持继续导出。
- 保存前和保存后均能直接重新录制；未保存可放弃，原片进废纸篓。取消导出返回工作区且保留原片，完成/关闭已保存的会话才清理原片。
- 失败：保留原因，返回后可以直接重试。

## 输出

- MP4 / H.264 / SDR / Rec.709。
- 采集与所有视频档位统一锁定最高 30 fps，实时硬件编码；静止画面可能少于 30 帧/秒。
- 高清保持原始尺寸，1080p 约 12 Mbps，4K 目标 32 Mbps；日常 1080p/30 帧/最高 4 Mbps；小巧 720p/30 帧/最高 1.2 Mbps；极小 480p/30 帧/最高 0.4 Mbps；自定义仅按体积调整尺寸和码率，帧率保持 30 fps。
- 高清压缩若体积更大或抽样像素损失过多，且原片不超过 30 fps，则保留原片；旧版 60 fps 原片必须转为 30 fps，不承诺每段原片都能进一步缩小。
- 保持原画面比例，不放大；竖屏使用旋转后的边界，小区域及低数据量原片进一步收紧预算。小体积档超出体积预算时降低实际尺寸，因此尺寸是上限。
- 自定义大小指每个 MP4 的上限，最低可填值按当前时长、尺寸、所选音轨对应的“极小”档体积预算向上取整到 0.1 MB；界面建议从该下限到原片体积附近的范围（建议上限并非硬限制）。预留音频和封装开销，压缩后量测，最多重试三次。无法满足则报错并保留原片，不交付超限文件。独立 M4A 另计。
- 实际平均码率与最终体积会随画面复杂度变化，声音轨也会占用少量空间。
- 电脑声音为 AAC 48 kHz 双声道，192 kbps。
- 人声默认关闭；开启后使用系统默认麦克风、AAC-LC 48 kHz 单声道、192 kbps。
- 合并导出：含视频时为一个 MP4，只有声音时为 M4A；两路声音混合为 AAC 48 kHz 双声道，视频中随档位使用 64–192 kbps，纯音频为 192 kbps。已生成的视频轨透传，不再次编码。
- 分轨：所选内容各一份，视频无声，电脑声音双声道 M4A，人声单声道 M4A；独立音频均为 192 kbps。不打包，时间误差不超过 40 毫秒。
- 下列默认文件名可在导出页修改，同名时整个导出批次统一追加编号。
- 完整视频文件名：`Snap 录屏 YYYY-MM-DD HH.mm.ss.mp4`。
- 分轨视频文件名：`Snap 视频 YYYY-MM-DD HH.mm.ss.mp4`。
- 分轨电脑声音文件名：`Snap 电脑声音 YYYY-MM-DD HH.mm.ss.m4a`。
- 分轨人声文件名：`Snap 人声 YYYY-MM-DD HH.mm.ss.m4a`。
- 保存位置：`~/Downloads`。
- 开启摄像头不增加任何导出选择，所有视频 MP4 都已经包含画中画；不输出单独摄像头文件。

## 不做

- 剪辑、变焦、字幕、摄像头分轨、云分享。
- 导出格式、分辨率、精细码率和文件夹选择。
- 麦克风设备选择、多显示器选择。
- 付费美颜组件、脸型重塑、美妆或身份识别。

## 首版验收

- 首次启动能解释权限用途，授权后可进入来源选择。
- 主面板可截图；整屏/局部录制时主动打开并放进画面的主面板可以录入。倒计时、录制 HUD、选区边框和摄像头预览不进入成片。
- 局部录像的固定比例在拖动后仍保持比例，自定义比例可自由改变；选区坐标与 Retina 输出像素正确对应。
- 聚焦蒙版默认圆角，可切换方角；框外为单色并压暗 50%，蒙版预览框不进入成片。
- 局部选区按 `⌘E` 后能够点击穿透，`⌘R` 可从下层应用直接开始；录制中按全局 `Esc` 能正常进入导出流程。
- 三种模式关闭“录制鼠标”后成片不出现系统箭头、光点或点击波纹；开启后显示圆形光点，点击波纹从真实点击位置扩散。
- 浏览器成片不出现其他应用、Dock、菜单栏、桌面图标或通知。
- 暂停后继续录制，暂停空档从最终文件中移除。
- 结束后无需选择路径即可在下载目录获得 QuickTime 可播放的 MP4。
- 开启人声后，合并文件同时包含电脑声音（如开启）与人声，视频画质不下降。
- 分轨且三项全选时得到无声 MP4、电脑声音 M4A、人声 M4A 三份，时长对齐且不生成 ZIP。
- 保存后可改内容、模式和名称继续输出；任一生成步骤失败都不会删除原始素材。
- 来源关闭或编码失败时给出明确反馈，不静默丢失。
- 摄像头默认关闭；只开摄像头、不开人声时，无麦克风权限请求，停止后进入相同导出页，不新增摄像头轨选择。
- 三种模式的人像均按成片右下角默认位置显示，圆角 / 圆形、三档大小、四角位置与镜像效果与设置一致；预览窗口不重复出现在成片。
- 摄像头开启后，四角位置卡片可反复切换，选中反馈与成片位置一致；点击卡片空白处也有效。
- 自然修饰默认关闭；开启后预览和成片使用同一处理结果，关闭后恢复原始画面。修饰不影响桌面内容，不改变五官形状；转头、说话和暂时离开画面时的效果稳定性及实时性能需要真实设备验收。
- 摄像头与屏幕动作同步；暂停区间从画面与声音共同移除，继续后不播放暂停前的人像残帧。
- 停止、关闭开关及闲置关闭主窗后，摄像头占用及时释放；拒绝权限、无设备、被占用与录制中断开均有明确提示。
- 摄像头真实设备录制与异常场景验收状态以 `docs/verification.md` 为准，开发说明不替代实际录制验证。
