## 屏幕、人像、声音，一次录齐。

打开摄像头，你的人像直接叠进画面；电脑声音和麦克风人声，跟画面同步录下。

<p align="center"><img src="https://shuyan-5200.github.io/snap-recorder/images/readme/portrait.png" width="100%" alt="左侧人像样式抽屉：四角位置、圆角或圆形、小中大三档、镜像，以及原图、自然、柔和三档自然修饰"></p>

- **位置、形状、大小，点一下就换**：四个角随你放，圆角或圆形，三档大小，还能镜像。
- **支持修饰，轻轻磨皮，人像自然**：原图、自然、柔和三档，只处理摄像头画面，全在本机完成。
- **支持鼠标入镜**：光标在成片里是准星，每次点击都有光晕扩散，操作步骤看得清。

## 清晰度、大小，全都由你定。

<p align="center"><img src="https://shuyan-5200.github.io/snap-recorder/images/readme/export.png" width="100%" alt="录制结束后右侧展开导出抽屉：勾选视频、电脑声音、人声，选择合并或分轨，拖动五档视频大小，填写文件名后保存到下载"></p>

| 档位 | 输出尺寸 | 适合 |
| :-- | :-- | :-- |
| **高清**（默认） | 原片 100%，最高 4K | 正式发布、留档 |
| **日常** | 原片 75% | 日常分享 |
| **小巧** | 原片 50% | 聊天里直接发 |
| **极小** | 原片 25% | 邮件附件、快速预览 |
| **自定义** | 填一个 MB 上限，每个文件都不会超过它 | 平台有大小限制时 |

- **合成一个，或分开存**：视频、电脑声音、人声，想要哪个勾哪个；单独导出声音，也可以。
- **点保存，就在「下载」里**：不用选目录，不用等上传，分轨文件整整齐齐。
- **想导几份，就导几份**：换清晰度、换组合，不用重录；已有文件，不会被覆盖。

## 三步开始

1. **下载**：[点这里下载 ZIP](https://github.com/shuyan-5200/snap-recorder/releases/download/v2.0.1/Snap-Recorder-v2.0.1-macOS-universal.zip)（约 2.5 MB），解压后把 Snap Recorder 拖进「应用程序」。
2. **授权**：第一次录制时，按提示允许「屏幕录制」。麦克风和摄像头只在你打开对应开关时才会请求。
3. **开录**：选好来源，按 ⌘R；录完命名、选好导出方式，点保存，文件就在「下载」里。

> [!NOTE]
> 应用还没有经过 Apple 公证。如果第一次打开被拦截，前往「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」即可，之后不会再提示。

运行环境：macOS 14 或更新版本，Apple Silicon 与 Intel 通用；录制人声需要 macOS 15 或更新版本。

## 常见问题

<details>
<summary><b>真的完全免费吗？</b></summary>
<br>
是的。没有付费版，没有试用期，也没有水印和广告。代码以 MIT 协议开源，个人和团队都可以自由使用。
</details>

<details>
<summary><b>能录多长时间？</b></summary>
<br>
不限时长。录多久取决于你的磁盘空间。
</details>

<details>
<summary><b>录好的文件在哪？</b></summary>
<br>
自动保存在「下载」文件夹，用你起的文件名。换个设置再导出一份，也不会覆盖已有文件。
</details>

<details>
<summary><b>会上传或收集我的数据吗？</b></summary>
<br>
不会。Snap Recorder 不需要账号，不联网，不做任何统计；画面、人像和声音全部在本机处理。
</details>

<details>
<summary><b>可以只导出声音吗？</b></summary>
<br>
可以。导出时只勾选「电脑声音」或「人声」，就能单独保存音频。
</details>

## 从源码构建

安装 Xcode Command Line Tools 即可，无需完整 Xcode，也不依赖任何第三方库：

```bash
swift build -c release
.build/release/SnapRecorder --self-test
./scripts/build-app.sh
```

构建结果为 `build/Snap Recorder.app`，同时包含 Apple Silicon 与 Intel 两种架构。打包直接使用 `app/SnapRecorderIcon.icns` 成品图标。

源码结构：

- `Sources/SnapRecorder/`：应用界面、采集、合成、导出与自检。
- `app/`：应用配置与打包所需图标。
- `scripts/build-app.sh`：构建与签名。
- `.github/workflows/`：自动构建、自检，以及产品主页发布。
